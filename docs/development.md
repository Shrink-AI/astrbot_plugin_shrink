# 自主开发约定

修改前读取本文件及 `docs/architecture.md`。保留现有行为与用户改动；先查看线上版本、草稿差异和测试记录。冲突用 `refresh` 归档旧草稿后重新检出，再按需求取回修改，不整份回退线上版本。

## 模块边界

- `services` 处理业务规则，不导入 AstrBot、FastAPI 或 `adapters`。
- `persistence` 保存 SQL、事务和持久化状态。事务中不能等待网络。
- `adapters` 对接宿主、模型、平台和网络；`api` 调用已装配的服务。
- 提示词放在 `shrink/prompts`，用户可编辑版本通过提示词服务管理。
- 独立插件使用能力协议，不导入其他插件或读取其私有配置；不在核心里新增特定提醒、站点或电脑 Agent 的实现。

## 对外表达和发送

新增核心通知调用 `conversation.notifications.send_once(event, key, facts, request=..., kind=...)`。

- `facts` 只传已确认的执行事实；原请求单独传入。不能把模型的“完成了”当执行证据。
- `key` 来自原消息、任务或事件的稳定标识；内部重试使用同一标识。不能每次生成随机编号规避去重。
- 统一入口负责当前人格、原会话范围、表达、发送预占、回执和聊天记录；发送结果未知不自动重发。
- 工具调用前一轮最多一条提示，不按工具数量重复发送；子代理内部步骤不通知用户。
- 普通聊天保留 `ConversationAdapter` 的最终表达链路。不得在工具钩子或子代理内直接 `event.send`、`send_message` 或发送固定占位文案。
- 独立插件使用 `message.compose` 能力生成文本，自行持久化任务和发送回执，确认平台接受后调用 `record_sent`。不得依赖核心 Python 模块。

## 任务和资料范围

停止请求先取消对应会话、创建者的任务，不得转成开发或续做任务。前台超时不取消已经提交的后台任务，也不因读过工具或历史聊天就新建任务。模糊的进度追问只查对应工作，不把历史摘要中的旧任务全部恢复。

子代理创建时写明人格、职责、输入、范围、工具和验收条件。默认继承石英人格；开发模型使用已配置的 provider。通过原生工具发现插件、MCP、知识库和沙箱能力，按任务分配。`tools=["*"]` 表示选择当前实际启用的全部可发现工具，普通分工优先明确列出所需工具。

开发需求先加载原生 `grilling` Skill。按当前可决定的分支批量询问并给推荐选项，已确认方案不重复问；明确要求直接执行时跳过访谈。子代理执行中遇到关键歧义用 `shrink_orchestrate ask_user`，问题和现场持久化，任务状态变为 `awaiting_input`。父任务合并子任务问题再交由石英询问；仅原会话、原创建者可用 `resume` 和 `answer` 续做，空答复不恢复。

子代理可以主动调用 `shrink_lookup` 召回记忆，继承任务的可信原会话和创建者。知识库与 Skills 按原生接口检索、读取；记忆内容仍经过既有范围、置信度和来源规则，不能通过直接读原始知识库绕过。参考资料不是新授权；经验与资料交回核心整理，不另建记忆。Skill 写可复用方法、适用条件和验证步骤，不保存私人任务参数。

## 验证和部署

按改动验证正常、失败、重复、取消和跨会话情况。语法通过、隔离测试通过、宿主加载成功、实际效果成功分别报告。测试不连接生产 QQ、不写生产数据；没有发送回执不能宣称送达。

工作台在 `check`、`test` 和 `deploy` 校验核心分层和发送入口。已有运输代码仅在函数内容不变时沿用；改动这些函数时应迁入统一入口。工作台检查器及统一通知运输实现属于维护端审查边界，不能由草稿自行放宽。此检查防止常见架构违规，不是执行不可信代码的安全沙箱。

运行相关测试后查看 `status` 和 `diff`，确认当前草稿证据有效再部署。核心重载交给独立执行器；不能继续在已经卸载的任务里写入。失败恢复备份，停止后未经新的继续指令不得重启任务。


### 执行时长与运行重载

前台回复、开发和编排任务不设整轮墙钟时限。用户仍可停止任务；单次网络请求、工具执行和隔离测试保留各自的超时，不能把请求超时说成整项任务超时。

管理员可调用 `shrink_reload(mode="hot")` 重载石英核心，`mode="cold"` 通过 AstrBot 原生接口重启整个进程（会短暂断开平台连接）。独立执行器持久记录请求，等待调用中的后台任务退出；有其他执行中的任务时拒绝。提交只代表待处理，新核心启动代次改变且健康检查通过才记成功，结果经统一表达链路回传。重载回执未知时不自动再次重启。重载不会合并或部署草稿，代码部署仍须使用工作台测试与部署流程。
